# עליזה ל-Word - POC (30.10.2026)

תוסף Office (Task pane add-in) ל-Word, מקומי לגמרי: אין Lovable, אין שרת של עליזה, המסמך לא יוצא מהמחשב.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `manifest.xml` | המניפסט של התוסף (אומת ב-office-addin-manifest validate: תקין). מצביע ל-https://localhost:3000 |
| `taskpane.html` | חלון המשימות: שלוש לשוניות (בדיקת צורה, נספחים, PDF ועליזה) |
| `analyzer.js` | מנוע הבדיקה: קורא את ה-OOXML של המסמך ובודק מול הוראת צורת מסמך |
| `serve.js` | שרת HTTPS מקומי קטן (Node, בלי תלויות) |
| `package.json` | סקריפטים: `certs`, `start`, `stop`, `validate` |
| `icon-*.png` | אייקונים |

## התקנה (Windows, Word של Microsoft 365)

דרישה: Node.js מותקן (`node -v`). אם אין: https://nodejs.org (גרסת LTS).

פותחים PowerShell בתיקייה הזו ומריצים, פעם אחת:

```
npm install
npm run certs
```

`npm run certs` יוצר תעודת HTTPS ל-localhost ומבקש אישור להתקין אותה כתעודה מהימנה. לאשר.

בכל פעם שרוצים לעבוד עם התוסף:

```
npm start
```

הפקודה מרימה את השרת המקומי, רושמת את התוסף ברישום של Office (HKCU\...\WEF\Developer) ופותחת את Word. בכרטיסיית **בית** מופיעה קבוצה "עליזה" עם הכפתור "עליזה ל-Word".

לסיום (חשוב, אחרת הרישום נשאר):

```
npm run stop
```

## מה אפשר לנסות

1. פתח כתב טענות קיים (או כל מסמך) ולחץ **בדוק את המסמך**. הדו"ח מציג: A4, שוליים 2.5 ס"מ, גופן (David / רעננה / Calibri), גודל 12 (כותרות עד 14), ריווח שורה וחצי, מספור עמודים, ומספר הנספחים שזוהו.
2. **תיקונים אוטומטיים**: A4 ושוליים; David 12 וריווח 1.5 (כותרות 14); הוספת שדה PAGE לכותרת התחתונה. הכול ניתן לביטול ב-Ctrl+Z.
3. לשונית **נספחים**: סריקה של "נספח א'", "נספח 3" וכדומה, ניחוש שם הנספח מהמשפט (ניתן לעריכה), ויצירת תוכן עניינים ודף מקדים לכל נספח בגופן David 36 בסוף המסמך.
4. לשונית **PDF ועליזה**: ייצוא PDF (ב-Word עדכני נשמר לתיקיית ברירת המחדל; אחרת קישור הורדה), וכפתורים שפותחים את עליזה בדפדפן.

## מה נבדק ומה לא

נבדק בסביבת הפיתוח: מנוע הבדיקה על קובצי docx אמיתיים (תקין ולא תקין), תקינות המניפסט, וזרימת הממשק מול חיקוי של Office.js (כולל תקינות ה-XML שהתוסף מזריק למסמך).

**לא נבדק בתוך Word אמיתי.** בפרט: `body.getOoxml()` אמור להחזיר גם את חלק הסגנונות (styles.xml); אם לא, התוסף מציג הערה והבדיקה נשענת על עיצוב ישיר בלבד. ייצוא PDF ב-Word ישן (בלי WordApiDesktop 1.4) דרך קישור הורדה בחלון המשימות עלול להיחסם.

## חלופה בלי Node

אפשר להגיש את התיקייה מכל שרת HTTPS (למשל תיקייה סטטית באתר), לעדכן את כל הכתובות `https://localhost:3000` במניפסט לכתובת החדשה, ולהתקין את המניפסט דרך "תיקייה משותפת מהימנה" (Trust Center > Trusted Add-in Catalogs) לפי התיעוד של מיקרוסופט.
